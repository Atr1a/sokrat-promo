# Промо-материалы детского клуба «Сократ»

## Игра-тест «Кем станет герой» — `index.html`

Игра для ребёнка и родителя: 10 шагов (имя и пол, возраст, друг-зверёк, 6 игровых вопросов и вопрос для взрослого). Для детей 6–7 лет — 11 шагов: «секретный уровень» про школу мечты, а в результате — блок о школе «Сократ» (преимущества с sokrat.school на 10.11.2026: прогулки на огороженной территории, своя кухня, классы до 15 детей, школа полного дня и 15 направлений на базе клуба, без тяжёлых портфелей) и путь «клуб сейчас → поступление → первый класс». В конце — «суперсила» ребёнка, три подходящих направления клуба с группами, временем и ценой, и купон со скидкой на первый абонемент с личным кодом вида `ГЕРОЙ-XXXX`.

- Один файл, без сборки и сервера: открывается в браузере или публикуется через GitHub Pages (Settings → Pages → ветка `main`, папка `/`).
- Персональные данные никуда не отправляются; имя и результат хранятся только в браузере устройства. На общем планшете перед следующей семьёй нажимать «Пройти ещё раз».
- Направления, группы и цены взяты из черновика нового сайта (ноябрь 2026); перед запуском сверить с единым справочником клуба.
- Скидка (20%) и срок записи на пробное (7 дней) задаются константами `DISCOUNT` и `BOOK_DAYS` в начале скрипта; условия утверждает директор.
